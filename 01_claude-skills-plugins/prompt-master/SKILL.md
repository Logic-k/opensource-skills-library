# Prompt Master

> **[Claude Code / Antigravity 스킬 & 플러그인](../README.md)** · 세부 장르: `Claude Code 스킬` · 상태: `보고 싶음`

막연한 한 줄 요청을 되묻고 구조화된 프롬프트로 바꿔주는 Claude 스킬. 30개 이상 AI 도구용 프롬프트 작성.

## 언제 꺼내 쓰나 (적재적소 활용 시점)

- 아이디어가 막연할 때 AI가 역질문(되묻기)을 통해 요구사항을 구체화하고 30+ AI 도구에 맞는 고품질 구조화 프롬프트로 변환하고 싶을 때

## 설치 및 활용 방법

- **가이드:** 저장소 클론 후 Markdown 스킬 파일을 Claude 스킬/프로젝트 지침에 추가
- **원클릭 로컬 클론 (이 폴더 옆 `./repo`에 소스 다운로드):**
  ```powershell
  powershell -File ..\..\scripts\clone-skill.ps1 prompt-master
  ```
- **상태 변경:**
  ```powershell
  python ..\..\scripts\manage_skills.py status prompt-master "사용 중"
  ```
