☁️ 클라우드 동기화 · 백업 · 웹 배포 설정

GitHub Pages·Vercel 같은 정적 웹에 배포한 상태에서도 스마트폰이나 외부 PC에서 스킬을 추가·수정·삭제할 수 있습니다.
아래에 본인의 GitHub 저장소와 Personal Access Token을 등록하면, 웹에서 수정할 때마다 GitHub의 catalog/skills.json과 web/data/skills.json을 직접 업데이트합니다.

토큰은 외부 서버로 전송되지 않고 오직 현재 브라우저의 localStorage에만 안전하게 보관됩니다.

📤 현재 서재 JSON 다운로드

웹에서 편집한 최신 서재 데이터를 skills.json 파일로 내려받습니다. 로컬 d:\Skills\catalog\skills.json에 덮어쓴 뒤 sync-catalog.ps1을 실행하면 마크다운 파일들도 한 번에 동기화됩니다.

📥 JSON 파일 가져오기 (복원/병합)

백업해 둔 skills.json 파일을 선택해 현재 서재로 불러옵니다.

🔄 브라우저 임시 저장소 초기화

현재 브라우저에 임시 저장된 편집 내역을 지우고 배포된 원본 데이터로 되돌립니다.

방법 1. GitHub Pages로 1분 만에 무료 배포하기 (가장 추천)

  1. GitHub에서 새 저장소(예: my-skills)를 만듭니다. (Private 저장소도 Pro 계정이면 Pages 가능, 일반 계정은 Public 또는 아래 Vercel 추천)
  2. d:\Skills 폴더 내용을 해당 GitHub 저장소에 푸시합니다. (이미 .github/workflows/deploy-pages.yml이 준비되어 있습니다!)
  3. GitHub 저장소 → Settings → Pages → Source에서 GitHub Actions를 선택하면 즉시 URL(https://아이디.github.io/저장소명/)이 생성됩니다.
  4. 이후 "☁️ GitHub 직접 저장 연동" 탭에 토큰을 1회 입력하면, 스마트폰·외부 PC에서도 편집 시 자동 커밋 & 자동 재배포됩니다!

방법 2. Vercel / Cloudflare Pages 무료 비공개(또는 개인) 배포

  1. GitHub 저장소를 Private으로 올려도 Vercel 또는 Cloudflare Pages에서 무료로 연결할 수 있습니다.
  2. vercel.json이 이미 설정되어 있어 저장소를 연결하기만 하면 web/ 폴더가 즉시 배포됩니다.

방법 3. 내 PC 로컬에서 파일과 실시간 연동 실행하기

.\scripts\start-web.ps1

로컬 서버 모드에서는 웹에서 추가·수정·삭제할 때마다 catalog/skills.json과 모든 SKILL.md, README.md가 즉시 자동 갱신되며, 상세 창에서 원클릭 git clone도 실행할 수 있습니다.
